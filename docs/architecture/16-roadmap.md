# 16 — Detailed Phased Implementation Roadmap

Every phase follows **PLAN → IMPLEMENT → RUN → TEST → DEBUG → VERIFY → DOCUMENT → COMMIT** and ends with a demonstrable "definition of done". No phase starts until the previous one runs and its tests pass. Estimated effort assumes focused sessions with the two agents.

## Per-phase ritual (what "DOCUMENT → COMMIT" means here)

- Update the relevant `docs/*.md` section and `AGENTS.md` if a convention changed.
- Add/refresh `CHANGELOG.md` entry `[Phase N] …`.
- Commit(s) on a `phase-N-<name>` branch; merge to `main` after the user confirms it runs.
